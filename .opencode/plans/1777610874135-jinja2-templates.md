# Plan: Migrate Boilerplate Generation to Jinja2 Templates

## Problem
The current TOPAS parameter file generation uses `ParameterEditor` (prefix-match line replacement on `List[str]`) and `@@PLACEHOLDER@@` string substitution. This approach is fragile, scatters parameter names across multiple files, and mixes template concerns with business logic.

## Approach
Replace the boilerplate system with Jinja2 template rendering. Convert all boilerplate files to `.j2` templates with proper variables and conditionals. Introduce a `TemplateRenderer` class. Refactor orchestrator and modes to build context dictionaries instead of doing line-by-line editing.

## Key Design Decisions

1. **Full conversion in one PR**: All 4 boilerplate files converted at once rather than incrementally
2. **Jinja2 conditionals for includes**: `{% if %}` blocks render only needed includes, no blanking
3. **Context dict pattern**: Modes return `dict` from `build_main_context(config)` / `build_sub_context(config)` instead of mutating `List[str]`
4. **TemplateRenderer encapsulation**: Jinja2 `Environment` configured once, templates loaded on demand
5. **Golden file snapshot tests**: Known-good TOPAS output for key configurations to catch template breakage

## Implementation Order

1. Add jinja2 dependency
2. Create `template_renderer.py` with unit tests
3. Create `.j2` template files from existing boilerplates
4. Add context builder methods to modes and orchestrator
